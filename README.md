# Забег Сосисек: Побег из Супермаркета

Аркадный раннер на Python + Pygame:
- Ландшафтная ориентация (1280x720).
- Движение слева направо через полосы гипермаркета.
- Управление W/S (линии), стрелками и свайпами мышью (эмуляция мобильных свайпов).
- Случайная генерация препятствий, врагов и бонусов.
- Есть низкие препятствия (коробки), которые можно перепрыгнуть.
- Есть длинные препятствия, для которых нужен более длинный прыжок.
- Есть навесные препятствия (вывески), под которыми нужно делать подкат.
- Постепенно растущая сложность.
- Внутриигровая валюта и апгрейды.
- Выбор вида сосиски с уникальными способностями.

## Установка

```bash
pip install pygame
```

## Запуск

```bash
python main.py
```

## Управление

- `W` — смена полосы вверх
- `S` — смена полосы вниз
- `← / →` — альтернативная смена полосы
- `↑ / Space` — прыжок
- `↓` — подкат
- Свайп мышью (или тач):
  - влево/вправо — смена полосы
  - вверх — прыжок
  - вниз — подкат

## Меню

- `A/D` или `←/→` — выбор сосиски
- `Enter` — старт
- `H` — улучшить здоровье
- `S` — улучшить скорость
- `C` — улучшить бонус монет

## Спрайты сосисок (PNG)

Чтобы использовать анимации из PNG, положите спрайт-листы (по 6 кадров в одну строку) в:

- `assets/sausage_classic.png`
- `assets/sausage_hunter.png`
- `assets/sausage_bavarian.png`

Прогресс сохраняется в `save_data.json`.
