# Забег Сосисек: Побег из Супермаркета

Аркадный раннер на Python + Pygame:
- Ландшафтная ориентация (1280x720).
- Движение слева направо через полосы гипермаркета.
- Управление W/S (линии), стрелками и свайпами мышью (эмуляция мобильных свайпов).
- Случайная генерация препятствий, врагов и бонусов.
- Есть низкие препятствия (коробки), которые можно перепрыгнуть.
- Есть длинные препятствия, для которых нужен более длинный прыжок.
- Есть навесные препятствия (вывески), под которыми нужно делать подкат.
- Постепенно растущая сложность.
- Внутриигровая валюта и апгрейды.
- Выбор вида сосиски с уникальными способностями.

## Установка

```bash
pip install pygame
```

## Запуск

```bash
python main.py
```

## Управление

- `W` — смена полосы вверх
- `S` — смена полосы вниз
- `← / →` — альтернативная смена полосы
- `↑ / Space` — прыжок
- `↓` — подкат
- Свайп мышью (или тач):
  - влево/вправо — смена полосы
  - вверх — прыжок
  - вниз — подкат

## Меню

- `A/D` или `←/→` — выбор сосиски
- `Enter` — старт
- `H` — улучшить здоровье
- `S` — улучшить скорость
- `C` — улучшить бонус монет

## Спрайты сосисок (PNG)

Чтобы использовать анимации из PNG, можно использовать любой формат:

1) Спрайт-лист (6 кадров в одну строку):

- `assets/sausage_classic.png`
- `assets/sausage_hunter.png`
- `assets/sausage_bavarian.png`
- Также поддерживаются пользовательские названия по ключевым словам
  (`classic|hunter|bavarian`) и короткий формат `assets/3.png`, `assets/2.png`, `assets/1.png`
  в порядке: `1 — Баварская`, `2 — Охотничья`, `3 — Классическая`.

2) Или папки с уже нарезанными кадрами `1.png ... 6.png`:

- `assets/sausage_classic/1.png ... 6.png`
- `assets/sausage_hunter/1.png ... 6.png`
- `assets/sausage_bavarian/1.png ... 6.png`

## Кастомный фон

Чтобы включить фон из скрина, положите изображение в:

- `assets/store_shelf_bg.png`

Игра автоматически подхватит его как основной задний фон.

### Инструкция «для чайника» (быстро и без боли)

1. Создай папку `assets` рядом с `main.py`, если её нет.
2. Фон:
   - сохрани картинку витрины как `store_shelf_bg.png`;
   - положи файл в `assets/store_shelf_bg.png`.
3. Спрайт-листы (по 6 кадров в ряд):
   - 1-й скрин (баварская) → `assets/1.png` **или** `assets/sausage_bavarian.png`;
   - 2-й скрин (охотничья) → `assets/2.png` **или** `assets/sausage_hunter.png`;
   - 3-й скрин (классическая) → `assets/3.png` **или** `assets/sausage_classic.png`.
4. Запусти игру: `python main.py`.
5. Если не подхватилось — проверь, что расширение именно `.png`, а имена файлов без пробелов.

Прогресс сохраняется в `save_data.json`.
