# Забег Сосисек: Побег из Супермаркета

Аркадный раннер на Python + Pygame:
- Ландшафтная ориентация (1280x720).
- Движение слева направо через полосы гипермаркета.
- Управление W/S (линии), стрелками и свайпами мышью (эмуляция мобильных свайпов).
- Случайная генерация препятствий, врагов и бонусов.
- Постепенно растущая сложность.
- Внутриигровая валюта и апгрейды.
- Выбор вида сосиски с уникальными способностями.

## Установка

```bash
pip install pygame
```

## Запуск

```bash
python game.py
```

## Управление

- `W` — смена полосы вверх
- `S` — смена полосы вниз
- `← / →` — альтернативная смена полосы
- `↑ / Space` — прыжок
- `↓` — подкат
- Свайп мышью (или тач):
  - влево/вправо — смена полосы
  - вверх — прыжок
  - вниз — подкат

## Меню

- `1/2/3` — выбор сосиски
- `Enter` — старт
- `H` — улучшить здоровье
- `S` — улучшить скорость
- `C` — улучшить бонус монет

Прогресс сохраняется в `save_data.json`.
